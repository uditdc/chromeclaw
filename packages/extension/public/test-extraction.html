ChromeClaw Page Context Extraction Test

This page contains various structured content types to test ChromeClaw's extraction engine. Each section below represents a different content type that the extractor should identify and categorize correctly.

Paragraphs

The page context engine uses Mozilla's Readability library to extract the main content from any web page. It strips away navigation, ads, sidebars, and other non-essential elements to provide clean, readable text to the AI.

Token estimation is performed by dividing the character count by 4, which provides a rough approximation of the number of tokens that the content will consume when sent to an LLM.

Code Block

function extractPageContext(options) {
  const clone = new DOMParser().parseFromString(
    document.documentElement.outerHTML,
    'text/html'
  );
  const article = new Readability(clone).parse();
  return {
    title: document.title,
    content: article?.content ?? '',
    extractedAt: Date.now()
  };
}

Lists

Ordered List: Build Steps

  1. Extract page metadata (title, description, OG tags)
  2. Run Readability to get main content
  3. Walk DOM for structured elements (tables, code, lists)
  4. Split content into token-bounded chunks
  5. Apply priority ordering and fit within budget
